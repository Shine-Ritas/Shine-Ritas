## About me

I'm **Ritas**, a **Software Engineer** based in **Bangkok, Thailand**, with **4+ years of experience** turning ideas into useful software.

My work spans **backend systems, payment integrations, database performance, and cloud infrastructure**. I care about clean architecture and the details that make software reliable: secure payment flows, resilient background processing, and systems that are easier to operate.

- **Backend** — Laravel and FastAPI, relational databases, and asynchronous processing.
- **Cloud** — AWS, Kubernetes, Terraform, and CI/CD.
- **Applied AI** — a locally hosted Python support assistant grounded in company data.
